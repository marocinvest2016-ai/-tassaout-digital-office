## 📌 نبذة عن النظام
مكتب تساوت الرقمي هو منصتك الرقمية المركزية لإدارة الإعلانات، العقارات، والأعمال التجارية في مدينة قلعة السراغنة وما حولها. يعتمد المستودع على محرك ذكي (**TASSAOUT OMEGA OS**) يقوم بالمعالجة التلقائية، ضبط الإضاءة السينمائية، وإصدار التقارير الرسمية المختومة.

---

## ⚙️ مكونات المستودع (Repository Structure)
- `app.py`: الواجهة التفاعلية الرئيسية (Streamlit) لإدارة وتقديم العروض.
- `requirements.txt`: المكتبات والتبعيات البرمجية المطلوبة للتشغيل على السحابة (Streamlit Cloud / Hugging Face).
- `README.md`: واجهة التوثيق والتعريف الرسمية للمكتب.

---

## 🚀 المميزات التقنية
1. **بروتوكول TASSAOUT MÉGA GO**: معالجة صور بمعيار 100MP Super-Resolution.
2. **التحكم الذكي بالإضاءة**: ضبط تلقائي (Bright Mode للأصول والعقارات / Cinematic Mode للسيارات).
3. **التوقيع والتصديق الرسمي**: إرفاق ختم مكتب تساوت الرقمي وتوقيع المدير التنفيذي (**Ameur signature**) تلقائياً في كل تقرير.
4. **التصدير الفوري**: ربط مباشر لإرسال التقارير والإعلانات عبر الواتساب.
